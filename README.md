A dying phone's last text at one percent battery: a confession that it kept snoozing its owner's 6am alarm every morning, and it is proud of it. The program in `main.ts` writes that single line (124 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
